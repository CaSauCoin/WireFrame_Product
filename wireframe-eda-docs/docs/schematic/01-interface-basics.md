# Interface & Project Management

Learn how to navigate the WireFrame workspace and manage your electronic design projects efficiently.

## Project Structure
WireFrame uses a structured XML-based file system to keep your designs organized:
* **`.prjxml`**: The root project file containing project-wide settings.
* **`.schxml`**: Schematic sheet files.
* **`.pcbxml`**: PCB layout files.

### File Operations
You can manage your design files directly within the Project Explorer panel:
* **Create/Delete:** Add new sheets or remove obsolete ones.
* **Rename/Move:** Reorganize files without breaking project links.

## Multi-Document Interface (MDI)
The editor supports MDI, allowing you to open multiple schematic sheets and libraries simultaneously.
* **Navigation:** Switch between active documents using the tab bar at the top of the workspace.
* **Keymap:** Fully customizable keyboard shortcuts (Settings > Keymap) allow you to tailor the controls to your preference.

## Workspace Tools
* **Title Block:** Automatically insert engineer details, dates, and revision numbers into your drawings.
* **Grid & Crosshair:** Toggle the grid snap and crosshair cursor to align components precisely.
* **Toolbar:** Quick access to primary modes: `Select`, `Wire`, `Component`, and `Graphics`.

> **Tip:** Customize your Keymap settings early to match your previous EDA tool experience for a smoother transition.
