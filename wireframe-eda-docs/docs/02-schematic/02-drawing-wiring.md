# Drawing & Wiring Tools

This section covers the core tools used to draw your circuit logic and visual annotations.

## Wiring & Connections
* **Wire Tool:** Connect pins to create nets. The tool snaps to pins automatically.
* **Buses & Labels:** (Coming soon) Use labels to connect distant points without physical wires.

## Graphic Primitives
WireFrame includes a set of geometric tools for drawing custom symbols or adding notes to your schematic:
* **Shapes:** Draw Rectangles, Polygons, Circles, and Lines.
* **Annotations:** Add Dots for connection junctions and Text for notes.

## Selection & Manipulation
Manage your canvas effectively with advanced selection modes:
* **Single Select:** Click to select an individual component or wire.
* **Box Select:** Hold `Ctrl` and drag to create a selection box (bulk selection).
* **Copy & Delete:** Standard clipboard operations are supported for single or multiple items.

## Component Properties
When a component is selected, the **Properties Panel** allows you to modify:
* Component values (Resistance, Capacitance, etc.).
* Footprint associations.
* Visibility of specific fields.
